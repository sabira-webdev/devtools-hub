# DevTools Hub

A collection of free online developer utilities designed to make everyday development tasks faster and easier.

🌐 **Live Website:** https://devtools-hubdev.netlify.app/

## Features

- **JSON Formatter** – Format, minify, validate and copy JSON.
- **Color Converter** – Convert HEX, RGB and HSL color formats.
- **Base64 Encoder/Decoder** – Encode and decode Base64 strings.
- **Code Snippet Library** – Browse and copy useful WordPress and PHP snippets.
- **WP_Query Generator** – Generate WordPress query code with customizable options.
- **Global Search** – Quickly find tools using Ctrl + K.

## Technologies Used

- HTML5
- CSS3
- JavaScript
- Vite

## Run Locally

```bash
git clone https://github.com/24sab/devtools-hub.git
cd devtools-hub
npm install
npm run dev
```
